# 🌲 Jharkhand Tourism Platform

A state-of-the-art Jharkhand Tourism platform designed to provide a premium, immersive experience for tourists while offering powerful administrative oversight through a data-driven dashboard.

## 🌐 Live Demo
🔗 **Visit the Live Application**: [https://jharkhandtourismm.netlify.app/](https://jharkhandtourismm.netlify.app/)


## 🚀 Features

### 🏨 Tourist Experience
- **Interactive Destinations**: Explore Jharkhand's waterfalls, temples, and hills with high-quality visuals.
- **Handicraft Marketplace**: Purchase authentic Dhokra art, Sohrai paintings, and local bamboo crafts.
- **Smart Booking**: Integrated rentals for vehicles, homestays, and tour guides.
- **AI Chat Support**: Real-time AI assistance for trip planning and local information.

### 🛡️ Administrative Dashboard
- **Visual Analytics**: Interactive visitor trends, destination popularity, and demographic charts.
- **Audit Records**: Full transparency with transaction logs for every purchase and rental.
- **Feedback Management**: Direct access to user reviews and ratings to improve local tourism services.

## 🛠️ Tech Stack

- **Frontend**: React.js, Vanilla CSS (Premium Custom Styling), React Router.
- **Backend**: Node.js, Express.js.
- **Database**: MongoDB (Local Persistence via LocalStorage for demo).
- **Icons & Graphics**: Custom SVG rendering for high performance.

## 📦 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/nishantsingh95/Jharkhand-Tourism.git
   cd Jharkhand-Tourism
   ```

2. **Setup Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Setup Backend**:
   ```bash
   cd ../backend
   npm install
   npm run dev
   ```
